# Project Metadata

- Name: Project Chimera – Autonomous Influencer Network
- Author: Suleyman Nurhussen
- Created: 2026-02-06

## Overview

This specs/ directory contains the authoritative, contract-level specifications for Project Chimera. These documents define what the system is allowed to do, how agents are expected to behave, and which constraints are non-negotiable.

These specifications are written to be:
- Readable by humans
- Enforceable by machines
- Sufficient for independent implementation

No agent, service, or human operator may assume  behavior that is not explicitly permitted here.
## Files

- `functional.md` — Functional specification describing agent-facing and operator-facing capabilities
- `technical.md` — Technical specification defining architecture, contracts, and non-functional guarantees
