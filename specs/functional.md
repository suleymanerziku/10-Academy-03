Agent-Oriented Stories

As a Planner Agent, I need to decompose high-level campaign goals into executable tasks so that workers can operate independently.

As a Worker Agent, I need to fetch platform trends via MCP so that generated content is contextually relevant.

As a Worker Agent, I need to generate video metadata (caption, hashtags, format) so that content can be published consistently.

As a Judge Agent, I need to evaluate outputs against acceptance criteria so that low-quality or unsafe content is rejected.

As a CFO Judge Agent, I need to validate cost estimates so that spending remains within budget.

Human-Oriented Stories

As a Human Operator, I need to review only flagged outputs so that I am not overwhelmed.

As a Human Operator, I need audit logs for agent actions so that accountability is preserved.
